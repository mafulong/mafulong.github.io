EVO75 灯光控制说明书

如果你用的是 EVOWORKS EVO75，关于”灯光关不了”的问题要特别注意：EVO75 有两套独立的灯光系统，关闭方法不一样：

  • 键盘按键 RGB（每键独立灯）
  • 顶部 / 侧边的 Ambient / Badge 灯（氛围灯和铭牌灯）

两套灯光用不同快捷键分别控制，不能一根快捷键一锅端。

按键 RGB（Per-key）

快捷键功能
Fn + Z开 / 关
Fn + X切换灯效
Fn + C上一个灯效
Fn + V / B色相 Hue + / -
Fn + N / M饱和度 + / -
Fn + < / >亮度 + / -
Fn + ↑ / ↓灯效速度 + / -

Ambient / Badge 灯（氛围灯）

快捷键功能
Fn + Q开 / 关
Fn + W切换灯效
Fn + E上一个灯效
Fn + R / T色相 Hue + / -
Fn + Y / U饱和度 + / -
Fn + I / O亮度 + / -
Fn + P / {灯效速度 + / -

注意：两套灯光的快捷键是错开设计的 — 按键 RGB 用 Z X C V B N M < > ↑ ↓，氛围灯用 Q W E R T Y U I O P {。这样盲操时不容易按错。

想全部关灯？按这个顺序

  1. Fn + Z — 关闭按键 RGB
  2. Fn + Q — 关闭 Ambient / Badge 灯

反过来开也是一样：先 Fn + Q 再 Fn + Z。

备忘

  • 这些快捷键在多份 EVO75 使用资料里一致，可以放心按。
  • 想调灯效但又不记得键位时，记住 Z 关 RGB、Q 关氛围灯这两条就够应急了。
  • 调亮度的键位 Fn + < / > 和 Fn + I / O 容易混 — 左边 < > 是 RGB，右边 I O 是氛围灯，两边都可以按，看你想调哪套。
