## 爱盯盘 / 大盘云图调研笔记

最近发现一个免费 A 股盯盘工具，叫 **爱盯盘**（[52etf.site](https://52etf.site/)）。核心功能是**大盘云图**：把沪深两市几千只票按行业板块拆成热力图（Treemap），**方块面积 = 市值权重，颜色深浅 = 涨跌幅**（绿涨红跌）。一句话概括：**一眼看完整个盘面谁强谁弱，不用一张张翻列表**。

顺手把它的插件文档（[52etf.site/blog/app/](https://52etf.site/blog/app/)）也翻了一遍，下面是笔记。

---

## 1. 大盘云图（主站）

### 1.1 解决了什么

盯盘时最大的痛点不是看不到行情，而是**信息密度太低**。东财、同花顺的板块列表一眼扫过去只能看到十几个板块，但板块内部的强弱排序、个股的相对位置完全看不出来。大盘云图直接用面积 + 颜色把"全市场强弱地图"压在一张图里，看一眼就知道：

- 今天谁是大盘主力（银行/白酒/宁组合 vs AI/券商）
- 哪个板块内部分化（同样涨 3%，有人涨 5% 有人平盘，色块深浅一目了然）
- 资金是否在切换（上午云图和下午云图颜色翻转 = 风格切换）

### 1.2 功能清单

- **多层级缩放**：默认看行业 → 滚轮钻进去看个股 → 双击个股跳 K 线
- **多市场视图**：A 股全图 / 上证 / 深证 / 沪深300 / 中证 A500 / 创业板 / 科创板，左侧一键切换
- **多周期切换**：当日 / 昨日 / 近一周 / 近一月 / 今年来 / 近一年 涨跌幅
- **复盘时间轴**：底部 09:30 / 10:00 / … / 15:00 几个时间点，可以回放当日盘面变化（键盘左右方向键也能切换）
- **截图分享**：一键导出当前盘面为 PNG，发群发雪球都方便
- **全屏模式**：右上角按钮，多屏盯盘友好

### 1.3 数据与限制（重要）

- **延迟行情**，非 Level-2，交易时段约 **每 8 秒刷新一次**。短线打板别指望这个
- 数据源：东方财富 + 同花顺 + 金融界
- **完全免费，无登录无注册**，打开就能用
- 支持港股（恒生、恒生科技）云图

## 2. 客户端分发（52etf.site/blog/app/）

主站是网页版，但站方也做了桌面端入口，方便上班摸鱼（[官方原话就是"摸鱼模式"](https://52etf.site/blog/app/#%E4%BD%BF%E7%94%A8%E6%8A%80%E5%B7%A7)）：

| 客户端 | 安装路径 | 国内可用 |
|---|---|---|
| Edge 浏览器插件 | [Edge Addons](https://microsoftedge.microsoft.com/addons/detail/ghgimmholcnejdgphgiiodmpgpefmppl) | ✅ |
| Chrome 浏览器插件 | [Chrome Web Store](https://chromewebstore.google.com/detail/stock-monitor-fund-assist/hmkhfephfjheodabgomnanpbmbjbepni) | ❌ 需翻墙 |
| 360 极速 / 安全浏览器 | 360 扩展中心搜"爱盯盘" | ✅ |
| uTools 插件 | uTools 插件市场搜"爱盯盘" | ✅ |

四种客户端功能基本一致，区别只在分发渠道。**Edge + uTools 这两条国内可用，墙内用户首选**。

---

## 3. 使用技巧（来自官方文档）

### 3.1 透明度 + 色彩度调节 → 摸鱼模式

把窗口调成半透明 + 低饱和度，放在 IDE 或文档后面，"看起来像是个不重要的小组件，实际上整张盘都在眼前"。上班党的盯盘标配。

### 3.2 点击个股 / ETF → 看 K 线

不跳出原窗口，直接在插件里查个股 K 线，免去来回切券商 App 的麻烦。

### 3.3 自选页

自选股单独一页，盯自己持仓不用每次都去云图里翻。

## 4. 跟同类工具对比

| 工具 | 形态 | 价格 | 强项 |
|---|---|---|---|
| **爱盯盘 / 大盘云图** | Web + 浏览器插件 + uTools | 免费 | 全市场热力图，最快扫盘 |
| 东财 / 同花顺 App | 手机 / PC 客户端 | 免费 + Level-2 收费 | 个股深度数据、Level-2 |
| 雪球 | Web + App | 免费 | 社区讨论、组合回测 |
| iFinD / Wind | PC 终端 | 年费几千~几万 | 机构级数据、研报 |

定位很清楚：**爱盯盘是"扫盘雷达"，不是"个股深挖工具"**。要扫盘看谁强 → 用它；要研究单只票的基本面/资金流 → 还是得回东财同花顺。

## 5. 我的评价

**优点：**

- 免费、无登录、开箱即用，没有比这更低的门槛
- 热力图这个形态本身就很适合 A 股几千只票的全景展示，比列表高效得多
- 复盘时间轴是亮点，能看到"10:30 → 11:00 → 14:00 主线风格怎么切的"
- 同时支持浏览器插件和 uTools，覆盖国内桌面场景

**短板：**

- 延迟 8 秒，**打板 / 短线神器用不上**，定位只能是"扫盘 + 中短线辅助"
- 网页版没法设置本地自选，所有自选存在云端，换浏览器就没了（插件版自选是本地的）
- 没有 Level-2、十档、盘口异动这些短线核心数据
- 港股支持比较浅，只有恒生和恒生科技，没做港股个股云图

**适合谁用：**

- 中长线 / 板块轮动选手（最契合）
- 上班想盯盘但不想明目张胆打开券商 App 的人（摸鱼模式就是为你准备的）
- 做板块复盘、需要快速对比当日各板块强弱的人

**不适合谁：**

- 打板 / 短线 / 需要 Level-2 的选手 → 老老实实回东财 L2

---

## 6. 一句话总结

**免费的 A 股热力图扫盘神器，定位是"看大盘"而不是"做交易"。** 装一个 Edge 插件或 uTools 插件当副屏，行情轮动时一眼看明白主线在哪，比手动刷板块列表快十倍。
