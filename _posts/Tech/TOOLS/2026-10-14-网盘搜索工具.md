## 新增：xunsoso 迅搜

[xunsoso.com](https://xunsoso.com) 是 2026-10-14 加进来的新站点，定位**非营利检索工具**，自己声明"所有内容均来自互联网公开引用资源，不存储/不上传文件"。

### 主要特点

- **主力索引迅雷网盘（迅雷），夸克网盘作为兜底** —— 站内筛选器默认就是「全部 / 迅雷」两个选项
- **多镜像域名** —— 进站后右上角可以切到延迟更低的镜像，挂了之后还有备用入口
- **4 套主题色** —— 暖红 / 海洋蓝 / 森林绿 / 暗夜黑，能切深色比较舒服
- **资源弹窗** —— 点资源后弹窗直接显示**分享链接 + 提取码 + 操作步骤**，支持**扫二维码**到对应云盘 App（迅雷 / 夸克）
- **磁力链接支持** —— 迅雷下载直接走 magnet
- **资源分享要 token** —— 想"分享资源上这个站"需要先在 B 站 / 知乎 / CSDN / 博客园 之一发一篇推广文，发完联系站长拿 token 存浏览器。**只是搜索这个 token 不是必需的**

### 体验

**优点：**

- 完全免费，**无登录、无注册**就能搜
- 数据走第三方公共 API，更新相对快
- 弹窗式呈现下载信息，省去跳转
- 多镜像 + 主题色 = 资源站常见的体验问题（加载慢、夜里刺眼）都给到了

**坑 & 注意事项：**

- **只索引、不存文件** —— 拿到链接后能不能下、能下多久全看原作者心情，**热门资源失效快**别囤
- **风险告知 / 免责声明挂在站内** —— 警惕搜索结果中夹杂的"假资源 / 钓鱼 / 私下交易"提示，站方把责任全甩给用户
- **提取码 + 跳转流程**对纯新用户稍微需要适应 —— 跟着弹窗提示走就行，复制链接 → 打开云盘 App → 粘贴提取码
- **资源分享流程**（那个 B 站/知乎/CSDN 推广门槛）可能让普通用户感觉麻烦，但反过来也意味着站内不会被营销号刷
- **联系方式只给了 ProtonMail** —— 版权投诉走邮件，没有在线工单
- 这类站点**生命周期都偏短**，记下域名 + 关注站内镜像切换，挂了能快速找到备用

### 谁适合用

- **找冷门学习资料 / 教程**：批量输入关键词，到迅雷 / 夸克 App 领
- **搭配 迅雷 / 夸克 客户端**：日常主力网盘是这两个的话，xunsoso 就是首选聚合源
- **不喜欢注册**：能直接搜是刚需
