中文

简述

Tab Sidebar 是一款纯本地的浏览器标签页管理扩展。它不会把你的任何信息发送到 Google 或任何第三方服务器 —— 没有账号、没有统计、没有广告、没有追踪。

收集哪些信息

不收集、不上传任何数据。

扩展只在本机读取并显示浏览器已经掌握的标签页信息（标题、网址、图标、所属窗口与分组、 是否为当前标签页、是否正在播放音频），这是扩展功能本身所必需的。这些数据不会离开你的设备。

数据存在哪里

数据存储位置说明
界面设置（默认视图、自动挂起时长等）chrome.storage.local保存在你的浏览器本地
标签页父子关系、折叠状态chrome.storage.session随浏览器会话结束而清除
缩略图截图chrome.storage.session只在内存中，最多保留 40 张
保存的会话chrome.storage.local仅在你点击「保存为会话」时写入

权限说明

权限用途
tabs读取并管理标签页：在侧边栏中显示标题 / 网址 / 图标，并支持排序、关闭、分组、拖拽
tabGroups读取和修改标签页分组，以便显示分组名与颜色
sidePanel在浏览器侧边栏中呈现扩展界面
storage保存上述设置、会话与界面状态
alarms每分钟检查一次是否有闲置标签页需要自动挂起（该功能可在设置中完全关闭）
sessions读取并恢复浏览器的「最近关闭」列表
clipboardWrite你点击「复制链接」或导出时，将内容写入剪贴板
<all_urls>（可选）仅在你主动开启「悬停显示缩略图」时才会申请，用于给你切换到的标签页截取一张小图。截图只保存在内存中，不会上传；关闭该功能会立即撤销此授权

第三方服务

没有。扩展不包含任何分析、统计、广告或远程代码，也不会与任何服务器通信。

儿童隐私

本扩展不收集任何个人信息，因此不涉及收集儿童个人信息。

政策变更

隐私政策如有变更，会更新本页顶部的「最后更新」日期。重大变更会在扩展的更新说明中提及。

联系方式

有关本扩展的问题，可通过 Chrome 网上应用商店页面上的「报告问题」联系。

English

Summary

Tab Sidebar is a fully local browser extension for managing tabs. It never sends any of your information to Google or to any third-party server — there are no accounts, no analytics, no ads, and no tracking.

What data is collected

No data is collected or transmitted.

The extension reads and displays only information the browser already has about your tabs (title, URL, favicon, owning window and group, whether it is the active tab, whether it is playing audio). This is strictly required for the extension to function, and this data never leaves your device.

Where data is stored

DataLocationNotes
Interface settings (default view, auto-discard interval, …)chrome.storage.localStored locally in your browser
Tab parent/child relationships, collapsed statechrome.storage.sessionCleared when the browser session ends
Thumbnail screenshotschrome.storage.sessionMemory only, at most 40 kept
Saved sessionschrome.storage.localWritten only when you click “Save as session”

Permissions

PermissionWhy it is used
tabsTo read and manage tabs: display their title / URL / favicon in the sidebar, and support reordering, closing, grouping and dragging
tabGroupsTo read and modify tab groups so that group names and colours can be shown
sidePanelTo present the extension UI in the browser side panel
storageTo persist the settings, sessions and interface state listed above
alarmsTo check once a minute whether idle tabs should be auto-discarded (the feature can be turned off entirely in settings)
sessionsTo read and restore the browser’s “Recently closed” list
clipboardWriteTo write links to the clipboard when you click “Copy link” or export
<all_urls> (optional)Requested only when you explicitly enable “Show thumbnails on hover”, and used solely to capture a small screenshot of the tab you switch to. Screenshots stay in memory and are never uploaded; disabling the feature revokes the permission immediately

Third-party services

None. The extension contains no analytics, tracking, advertising or remotely hosted code, and it never communicates with any server.

Children’s privacy

The extension does not collect any personal information, so it does not collect information from children.

Changes to this policy

If this policy changes, the “Last updated” date at the top of this page will be updated. Material changes will also be mentioned in the extension’s release notes.

Contact

Questions about this extension can be sent through “Report an issue” on the extension’s Chrome Web Store listing.
