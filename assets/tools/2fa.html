2FA 验证码工具

纯静态单文件 HTML / JS 实现，所有计算均在浏览器本地完成，不会把任何密钥内容发送到任何服务器，也不会写入本地存储—— 刷新或关闭页面后左侧内容会自动清空，请放心粘贴密钥。

输入密钥（每行一个场景）

支持三种写法（三选一，可混用）：
1. 场景名,密钥 或 场景名 密钥（逗号 / Tab 分隔，推荐）
2. 场景名 密钥（空格分隔，密钥内部允许有空格，会自动去除）
3. 完整的 otpauth://totp/...?secret=... 链接（扫码软件导出的格式）
密钥仅支持标准 Base32 编码、算法仅支持 SHA1（绝大多数验证码场景均为此类型）。
